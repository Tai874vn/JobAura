JOBAURA FRONTEND: WHERE THINGS ARE
==================================

src/
  app/          Next.js routes. One folder per URL; page.tsx only loads data and renders a feature component.
                Folders in (brackets) group routes without changing the URL: (marketplace) public, (workspace)
                signed-in, (admin) admin, (auth) logout.
  features/     Everything for one part of the product (see the layout below).
  shared/       Used by many features:
    api/        HTTP client, one file per backend area in api/endpoints/, React Query keys, normalizers
    ui/         Buttons, inputs, dialogs, browse-page layout, pagination
    lib/        Small helpers (errors, SEO, URL, dates)
    schemas/    Zod types for API data
    stores/ realtime/ providers/ config/ icons/
  proxy.ts      Edge proxy: sends signed-out visitors to /auth/login for private pages.
  instrumentation*.ts   Sentry setup.

Every feature folder has the same layout:
  features/<name>/
    api.ts          calls to the backend (when the feature has its own)
    components/     React components (.tsx); big features split them by screen, e.g. components/browse/
    hooks/          use-*.ts React hooks
    utils/          plain functions without UI (labels, rules, formatting, cache refresh)
  Tests live in a __tests__ folder inside the folder of the code they test, e.g.
    features/contracts/utils/status-labels.ts
    features/contracts/utils/__tests__/status-labels.test.ts
  (Next.js ignores folders that start with "_", so __tests__ inside app/ never becomes a page.)

Features:
  admin           admin dashboard and the admin tables (users, jobs, categories, comments)
  auth            sign-in, sign-up, email confirm, forgot/reset password, Google callback, session hook
  candidates      candidate directory and AI-recommended candidates (recruiter)
  chat            chat window and rooms
  connections     connections page and connect button
  contracts       proposals, contracts, milestones, changes, ending, reviews
  feed            home feed, posts, comments, reactions
  hiring          hiring posts: browse, detail + apply, my hiring posts, post form
  hiring-pipeline applicants board (recruiter), my applications (candidate), interview video call
  jobs            services (portfolios): browse, detail, create/edit form, welcome page, AI job picks
  layout          header, footer, public page shell
  notifications   bell and list
  occupations     occupation and specialty pickers
  saved           saved items page
  users           profile page, resume, skills and certifications
  wallet          wallet page, ledger, Stripe top-up and return page
  workspace       settings pages, my posts
